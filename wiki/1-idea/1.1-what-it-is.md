# 1.1 What llm-whisperer is

> **Status:** Implemented — describes shipped behaviour of 0.1.5.

llm-whisperer is a small local HTTP server. You start it, it listens on
`localhost:9777`, and anything that can speak the OpenAI or Anthropic HTTP APIs
can now talk to eighteen different model providers without knowing anything
about them.

```
your app ──▶ http://localhost:9777 ──▶ LLM-Whisperer ──▶ any provider you pick
```

The whole product is that arrow in the middle. It is roughly 1,300 lines of
TypeScript and one 284-line YAML file, and the YAML is the more interesting
half — see [§2.2](../2-architecture/2.2-configuration-is-the-product.md).

## The problem it was built for

The pitch that stuck, from the author's own notes in `todo`:

> For all the token-poor people out there — what if you could pool all those
> free LLM tiers into one unified API endpoint?

Every provider hands out a free tier. Gemini, Groq, Cerebras, Mistral,
OpenRouter and Cloudflare Workers AI all do. Individually each one runs dry
fast. The observation behind llm-whisperer is that they run dry *at different
times*, and that the only thing stopping you from hopping between them is that
each has its own SDK, base URL, auth header and model naming.

So: put one OpenAI-compatible endpoint in front of all of them, and switching
provider becomes editing a string.

```bash
curl http://localhost:9777/v1/chat/completions -H "Content-Type: application/json" \
  -d '{"model":"groq","messages":[{"role":"user","content":"Hello!"}]}'
#            ^^^^ change this word, change provider
```

That string is the entire switching mechanism. [§3.2](../3-api/3.2-choosing-a-model.md)
covers what it can and cannot do.

## What it is not

- **Not a router.** There is no automatic failover, no "try Groq, fall back to
  Cerebras when the quota is gone", no load balancing, no retry. You name a
  provider and it calls that provider. Pooling free tiers is something *you* do
  by changing the model string; the tool makes it cheap, not automatic.
- **Not a cache, a logger, or a cost tracker.** Token counts in every response
  are hard-coded `0` — see [§3.1](../3-api/3.1-three-dialects.md#what-the-response-does-not-contain).
- **Not a model.** It ships no weights and runs no inference.
- **Not multi-user.** There is one optional shared secret ([§3.4](../3-api/3.4-embeddings-and-auth.md#the-auth-gate)),
  no accounts, and a browser session pool that assumes one person is using it.

## Shape of the thing

| | |
|---|---|
| Language | TypeScript, ESM, targeting Node ≥ 18 |
| Published as | [`llm-whisperer`](https://www.npmjs.com/package/llm-whisperer) on npm, latest `0.1.5` |
| Command | `wspr` (`dist/cli.js`) |
| Source | 8 files under `src/`, ~1,290 lines |
| Runtime deps | `express`, `playwright`, `playwright-extra`, `puppeteer-extra-plugin-stealth`, `js-yaml`, `dotenv` |
| Automated tests | **none** |

That last row is not an oversight to be embarrassed about in a footnote — it is
a fact that changes how you should read the rest of this book. Nothing in this
codebase is protected by a test. Where a page says something is verified, it
means a human ran it once and wrote down what happened; [§8.2](../8-about/8.2-vocabulary.md)
defines exactly how much that is worth.

The one thing that *is* checked automatically is TypeScript itself:

```console
$ npx tsc -p tsconfig.json --noEmit
$ echo $?
0
```
